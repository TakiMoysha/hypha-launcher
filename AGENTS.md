# Agent Note

## How perform agents work

- `AGENTS.md`: принятые ключевые решения, принципы разработки, тулинг и доки по ним (как я это решаю). Не нужно писать детали реализации, описывай здесь системы и архитектуру, принципы разработки и ссылки на skills. Все, что применимо к проекту глобально.
- `MEMORY.md`: состояние проекта и контекст для агента (что я знаю о коде сейчас). Тоже не нужно документировать все подрят, только ключевые вещи.

#### How work with docs and artifacts:

Когда ты реализуешь задачу `F`, то ее нужно записать в `MEMORY.md` как систему (абстракцию, без деталей реализации). Откуда приходят данные, как преобразуются, куды выходят. Для этого есть глава `AIJobs`, ты добавляешь `F` к списку задач и добавляешь подглаву о реализации. Если `F` уже встречается - читай ее контекст и дополняй.

Указывать лучше markdow-ссылки на файлы, вместо простого обозначения.

If PR/Contribution is done by an agent (or meaningful assistance), this must be clearly stated. Example: `- [x] This PR is done by an agent`.
